Paper Orbit

论文智能阅读系统。上传论文后做解析、分段、向量检索和问答，回答里会带来源位置。

  • 后端：FastAPI、Pydantic、LangChain、ChromaDB。
  • 前端：React、TypeScript、Vite。
  • 公开版去掉了 API Key、上传文件和运行时数据库。

PaperPilot Lite

一个更轻量的论文阅读助手原型，用来验证本地解析、摘要、证据约束问答这些功能。

  • 支持 PDF / TXT / Markdown。
  • 可以在没有模型 API 的情况下跑本地分析。
  • 包含测试、示例文件和页面截图。
