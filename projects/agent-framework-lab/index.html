Agent Framework Lab

一组智能体框架练习代码，用来理解角色、消息、状态、任务分解和图式工作流。

源码 README

内容

  • AutoGen 风格的软件团队协作模拟。
  • AgentScope 风格的多角色消息中心。
  • CAMEL 风格的角色扮演和任务分解。
  • LangGraph 风格的节点、边和条件跳转。
