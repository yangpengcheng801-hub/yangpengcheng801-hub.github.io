PaperPilot Lite

一个轻量的论文阅读助手原型，主要验证本地解析、摘要、证据检索、问答和笔记导出流程。它更适合快速试功能，也方便继续改成完整 RAG 项目。

源码 README 返回项目列表

功能

  • 支持 PDF / TXT / Markdown。
  • 抽取摘要、关键词、方法、结果和局限。
  • 问答时返回相关证据片段。
  • 可以导出 Markdown 阅读笔记。

运行

cd projects/paperpilot-lite
python -m pip install -r requirements.txt
python app.py

默认打开：`http://127.0.0.1:8765`。

我主要写的部分

  • 用标准库 HTTP server 做一个轻量本地 Web 入口。
  • 整理论文解析、结构化摘要、证据片段检索和导出流程。
  • 补示例文档、截图和测试，方便别人直接试。

公开版本说明

目录里保留了源码、测试、示例和截图；没有提交真实密钥和本地缓存。基础流程不依赖模型 API，配置后可以接入 LLM 做更完整的问答。
