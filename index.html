Paper Orbit

论文智能阅读系统。上传论文后做解析、分段、向量检索和问答，回答里会带来源位置。

  • 后端：FastAPI、Pydantic、LangChain、ChromaDB。
  • 前端：React、TypeScript、Vite。
  • 公开仓库不包含 API Key、上传文件、向量库数据和依赖缓存。

运行说明

先看页面

从项目页进入源码目录，先看功能、流程、运行命令和关键文件。

  • /projects/
  • /projects/paper-orbit/

本地运行

PaperPilot Lite 和 Agent Framework Lab 可以先不配模型密钥运行基础流程。

  • python app.py
  • python scripts/lab0_run_all_minimal.py

完整 RAG

Paper Orbit 需要配置模型 API Key 和 embedding 模型后启动前后端。

  • copy backend\.env.example backend\.env
  • npm run dev
