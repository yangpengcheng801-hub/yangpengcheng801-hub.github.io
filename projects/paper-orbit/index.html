Paper Orbit

一个论文阅读 RAG 项目。上传 PDF 或 Word 后，后端解析文档、切分片段、写入向量库；提问时先检索相关片段，再生成回答和来源。

源码 README

流程

PDF / Word
  -> parse
  -> chunk
  -> embedding
  -> ChromaDB
  -> retrieve
  -> answer with sources

技术栈

PythonFastAPILangChainChromaDB ReactTypeScript

我主要做的部分

  • 整理上传、解析、检索、问答的后端接口。
  • 把 PDF / Word 文档拆成适合检索的文本片段。
  • 用向量库保存片段，问答时返回相关来源。
  • 做了 React 前端，用来上传论文、查看目录和提问。

本地运行

cd projects/paper-orbit
npm install
npm run setup
copy backend\.env.example backend\.env
# 编辑 backend\.env，填写自己的 LLM_API_KEY
npm run dev

公开仓库不包含真实密钥、本地上传文件、ChromaDB 数据库和 node_modules。完整运行需要自己准备模型 API Key 和 embedding 模型。
