Agent Framework Lab

一组智能体框架练习代码，用来理解角色、消息、状态、任务分解和图式工作流。这个项目偏学习和机制拆解，不包装成完整产品。

源码 README 返回项目列表
AutoGen团队协作模拟
CAMEL角色扮演和任务分解
LangGraph节点、边、状态
No key基础实验可直接跑

内容

  • AutoGen 风格的软件团队协作模拟。
  • AgentScope 风格的多角色消息中心。
  • CAMEL 风格的角色扮演和任务分解。
  • LangGraph 风格的节点、边和条件跳转。

运行

cd projects/agent-framework-lab
python scripts/check_env.py
python scripts/lab0_run_all_minimal.py

基础实验会把输出写到 `outputs/`，这个目录不会提交到公开仓库。

我主要写的部分

  • 把几个框架的核心概念拆成不依赖外部 API 的最小实验。
  • 整理脚本，一条命令跑完基础实验，便于复现。
  • 保留真实框架模板，用环境变量读取配置，避免提交密钥。
