# Agent Framework Lab

一组智能体框架练习代码，用来理解角色、消息、状态、任务分解和图式工作流。

## 内容

- `autogen_style_software_team.py`: 软件团队协作模拟。
- `agentscope_style_werewolf.py`: 多角色消息中心和行动模拟。
- `camel_style_book_writing.py`: 角色扮演和任务分解写作流程。
- `langgraph_style_dialogue_workflow.py`: 图式对话工作流。
- `streamlit_bitcoin_app.py`: 简单数据应用。

## 运行

```powershell
cd projects/agent-framework-lab
python scripts/check_env.py
python scripts/lab0_run_all_minimal.py
```

## 说明

`labs/` 里的教学版实验不需要 API Key。`framework_templates/` 是真实框架模板，只读取环境变量，不包含密钥。
