Paper Orbit

一个论文阅读 RAG 项目。上传 PDF 或 Word 后，后端解析文档、切分片段、写入向量库；提问时先检索相关片段，再生成回答和来源。

源码 README 返回项目列表
FastAPI上传、解析、问答接口
ChromaDB本地向量库
React阅读和提问界面
Sources回答返回证据片段

流程

上传PDF / Word
解析正文和章节
切分检索片段
检索Embedding + ChromaDB
回答答案和来源

技术栈

PythonFastAPIPydanticLangChain ChromaDBPyMuPDFpython-docxReactTypeScript

我主要写的部分

  • 整理上传、解析、检索、问答的后端接口。
  • 把 PDF / Word 文档拆成适合检索的文本片段。
  • 用向量库保存片段，问答时返回相关来源。
  • 做 React 前端，用来上传论文、查看目录、阅读和提问。

本地运行

cd projects/paper-orbit
npm install
npm run setup
copy backend\.env.example backend\.env
# 编辑 backend\.env，填自己的 LLM_API_KEY
npm run dev

默认端口：Backend `http://127.0.0.1:8000`，Frontend `http://127.0.0.1:5173`。
